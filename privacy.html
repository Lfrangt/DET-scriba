隐私政策

适用于：DET 精批 iOS 应用  ·  生效日期：2026 年 5 月 10 日

DET 精批（以下简称"本应用"）是一款 DET 英语写作练习工具，帮助用户备考 Duolingo English Test。本应用由个人开发者 吴昊格（Hallidai Inc.） 开发和维护。

本政策说明本应用如何处理您的数据。

§1 我们收集的数据

数据类型 具体内容 用途 存储位置
写作内容 您输入的题目和作文 发送给 AI 进行批改 本地（SwiftData）+ 传输至 AI 服务
设备标识符 设备供应商 ID（IDFV，即 identifierForVendor） 免费托管模式下的频率限制（防止滥用），不用于广告或跨 App 追踪 仅发送至本应用 Vercel 代理服务器，不持久化存储
应用设置 AI 提供商选择、自定义端点（不含 API Key） 记住用户偏好 本地（UserDefaults，设备内）
API Key 您在 BYOK 模式下填写的第三方 API Key 直连您选择的 AI 服务 本地（iOS Keychain，设备内）

本应用不收集：姓名、邮箱、手机号、位置、通讯录、健康数据、相机、麦克风、照片库。

§2 数据如何被使用

2.1 免费托管模式（默认）

您的作文文本 + 设备 IDFV 被发送至本应用的 Vercel 代理服务器（det-scriba.vercel.app），再转发至 DeepSeek API 进行批改。

  • 代理服务器不持久化存储您的作文内容
  • IDFV 用于每日请求限额（20 次/天），不与任何账号或个人信息关联
  • DeepSeek 的数据处理受其自身隐私政策约束

2.2 BYOK 模式（自带 API Key）

您的作文文本直接从设备发送至您选择的 AI 服务（DeepSeek / OpenAI / Anthropic / 自定义端点）。本应用开发者不接收也无法访问这些请求的内容。

§3 本地数据存储

所有批改结果、历史记录、笔记均存储在您设备本地（SwiftData），不同步至任何服务器。卸载应用将删除全部本地数据。

§4 数据共享

我们不向第三方出售、出租或交换您的任何数据。以下情况除外：

  • AI 服务商（见 §2）：发送您的作文文本以完成批改功能
  • 法律要求：当法律法规明确要求时

§5 数据安全

  • API Key 存储在 iOS Keychain（加密隔离）
  • 与代理服务器和 AI API 的所有通信均使用 HTTPS/TLS
  • 不存在用户账号体系，无法通过密码泄露影响您

§6 儿童隐私

本应用不针对 13 岁以下未成年人，也不故意收集其数据。如发现有误，请联系我们删除。

§7 隐私政策更新

如本政策发生重大变更，我们将更新本页面的生效日期。建议定期查看。
