选择对比类 · 正反方万能观点

1. 方便（convenience）

【优点】某行为(v.ing) / 某物(n.) can bring more convenience to 谁

【缺点】某行为(v.ing) / 某物(n.) can bring some inconvenience to 谁


2. 收益（profits）

【优点】某行为(v.ing) / 某物(n.) can bring more profits to 谁

【缺点】某行为(v.ing) / 某物(n.) can cause the financial loss of 谁


3. 花费（cost）

【优点】某行为(v.ing) / 某物(n.) can save the cost (of 什么 fees) for 谁

【缺点】某行为(v.ing) / 某物(n.) can increase the cost (of 什么 fees) for 谁


4. 时间（time）

【优点】某行为(v.ing) / 某物(n.) can save time for 谁 (to do sth)

【缺点】某行为(v.ing) / 某物(n.) can waste time for 谁 (on doing sth)


5. 健康（physical health）

【优点】某行为(v.ing) / 某物(n.) can make 谁 healthier

【缺点】某行为(v.ing) / 某物(n.) can make 谁 unhealthier


6. 压力（pressure）

【优点】某行为(v.ing) / 某物(n.) can release the pressure upon 谁

【缺点】某行为(v.ing) / 某物(n.) can lay more pressure upon 谁

7. 发展（development）

【优点】某行为(v.ing) / 某物(n.) can speed up the growth (of …) for 谁

【缺点】某行为(v.ing) / 某物(n.) can stand in the way of the growth (of …) for 谁


8. 氛围（atmosphere）

【优点】某行为(v.ing) / 某物(n.) can create a positive … atmosphere for 谁

【缺点】某行为(v.ing) / 某物(n.) can create a negative … atmosphere for 谁


9. 知识（knowledge）

【优点】某行为(v.ing) / 某物(n.) can help obtain more knowledge (of …) for 谁

【缺点】某行为(v.ing) / 某物(n.) can narrow the knowledge (of …) for 谁


10. 环境（environment）

【优点】某行为(v.ing) / 某物(n.) can preserve the environment for the mankind

【缺点】某行为(v.ing) / 某物(n.) can destroy the environment for the mankind


11. 需求（demand）

【优点】某行为(v.ing) / 某物(n.) can meet 谁’s demands for …

【缺点】某行为(v.ing) / 某物(n.) can violate 谁’s demands for …


12. 安全（safety）

【优点】某行为(v.ing) / 某物(n.) can guarantee the safety (of …) for 谁


【缺点】某行为(v.ing) / 某物(n.) can damage the safety (of …) for 谁
